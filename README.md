# TRACE

TRACE is a premium, privacy-conscious digital footprint awareness dashboard.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Current build

Phase 1 includes:
- Landing page
- Digital Footprint 101
- Analyze flow with demo scanning
- Dashboard
- Trends
- Monthly Analysis
- Compare
- Footprint Breakdown
- Privacy
- History
- Settings
- Responsive dark lavender/cyan UI
- Demo charts and historical snapshots

The next phase can add authentication, Supabase/PostgreSQL, and legitimate public APIs such as GitHub.
